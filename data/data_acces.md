# Data Access

Raw data are not committed to this GitHub repository. Place the input files in
the paths below before running the notebooks.

## Required Local Files

### `data/Hg19/`

- `E_VPR-KRAB_CraTEs.txt.gz`
- `N_c_100_Hg19_craTEs.tsv`
- `N_w_2.5e5_Hg19_craTEs.tsv`
- `2110_hg19_annotation.csv`

### `data/Hg38/`

- `E_Senescene_TE_Seq_raw.tsv`
- `E_TE-Seq_prep_results.tsv`
- `GSE280365_resultsdf.tsv`
- `GSE280365_sample_metadata.tsv`

- `N_w_2.5e5_Hg38_craTEs.tsv`

## Notes

- Keep raw data local unless redistribution is explicitly allowed.
- The weighted `N_w_2.5e5_*` files are large and should not be committed to
  normal GitHub storage.
- If public archiving is needed, use a data repository such as Zenodo, OSF, or
  an institutional repository, then link the DOI or accession here.
